# Kinetic Text & Motion Graphics Treatment

## Intent

The reference visual master stays untouched (character animation, camera, background). Kinetic text and motion graphics are added as a **separate overlay layer** on top of the 10 storyboard panels defined in `completed_storyboard.md`. This layer carries emphasis, structure cues, and section markers so the 8:02 program reads as a designed explainer, not a held loop.

## System

- **Typeface:** geometric sans (Inter / Space Grotesk / DM Sans family). Heavy weight for headline emphasis, medium for body callouts, mono for numbered chips.
- **Palette (matches the mint/cyan line-art already in the background):**
  - Primary text: `#F2F6FA` (off-white)
  - Accent line / underline / chip: `#7EE6D5` (mint, matches environment strokes)
  - Warning accent (used only in Panel 07): `#FF9F6B` (coral-orange, distinct from character coral)
  - Text shadow: `rgba(6, 12, 24, 0.65)` — subtle so type stays readable over the navy without a hard drop shadow
- **Safe area:** all overlays live inside the top and bottom sixths of the frame, or in the central negative space between the protagonist and the group. Overlays never cross a character's face, hoodie/shirt logo area, or hands mid-gesture.
- **Motion vocabulary (five moves, no more):**
  1. `WIPE-UP` — text slides in from below with a soft ease, ~10 frames.
  2. `TYPE-IN` — mono-space character-by-character reveal for numbered chips.
  3. `UNDERLINE-DRAW` — a mint stroke draws left-to-right under a landing word.
  4. `PULSE-RING` — a single mint ring pulses out from a target point (used to mark "the gap").
  5. `CROSSOUT` — a single stroke passes through text once to negate it (used in Panel 07).

Every panel below lists only overlay work. The character animation and camera behavior remain as specified in `completed_storyboard.md`.

## Delivery notes

- All overlay work sits on a **single After Effects / Motion / Rive composition** stacked above the reference video track. The reference master is never re-timed or altered.
- Motion easing: prefer a small custom ease-out on `WIPE-UP` (a soft settle) rather than default linear. Keep every entrance under 12 frames at 24 fps.
- HUD chips (Panels 03–06 and 10) are the only persistent overlay. Everything else clears before the next panel to keep frames breathable.
- No overlay ever covers a character's face or hand mid-gesture; the safe-area rule at the top of this doc governs layout.
- The `UNDERLINE-DRAW` accent line always uses the environment mint `#7EE6D5` so the overlay reads as part of the same drawn world.
