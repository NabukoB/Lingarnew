# Market Scan · Ep 1 — Animated Explainer

Self-playing animated explainer built to the exact production package for
Episode 1: *I Used AI to Find "Zero Competition" Products in Kenya — Half of
Them Were Fake*.

Runs in a browser as a single static HTML page — no build step, no deps.
Open `index.html` locally or serve the folder from any static host.

## What's in it

- 12 storyboard shots, ~8:45 runtime, keyed to one master playhead
- Transport (play / pause / restart / scrub / 0.5×, 1×, 2× speed)
- Shot-chip picker; keyboard: Space toggles play, ← / → seek ±5s
- VO caption strip; live "Now Playing" panel with shot / segment / motion
- The exact palette (ink · paper · green · red · gold) and type pair
  (Anton + Archivo) called out in the production package
- Reusable niche-score card component; card-flip in, red-X stamp,
  Xbox/PC vs PS5 plate cross-out, and the 20K budget bar segmented live

## Notes

- Numbers on the cards match the script's Jiji Scout + Jumia checks. Phone-case
  price is labeled explicitly as wholesale to match the correction in the
  research-evidence section of the package.
- The end-teaser tees up Episode 2 ("Repair & Construction").
